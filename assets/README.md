## 1. Zweck eines Asset-Registers

Das Asset-Register dokumentiert die wensentlichen Informationswerte (Assets) der fiktiven Noventis Group GmbH. Es bildet eine Grundlage für die Identifikation, Bewertung und Behandlung von Informationssicherheitsrisiken im rahmen dieses ISMS-Projekts. 

Das Register unterstützt insebesondere: 
- die Identifikation und Zuordnung schützenswerter Informationswerte.
- die Festlegung von Asset-Ownern und Verantwortlichen.
- die Bewertung von Vertraulichkeit, Integrität und Verfügbarkeit.
- die Einschätzung der Kritikalität einzelner Assets.
- die Verknüpfung von Assets mit identifizierten Risiken.
- die Ableitung geeigneter Sicherheitsmaßnahmen nach ISO/IEC 27001:2022.

## 2. Aufbau des Register 

das Register ist als Excel-Datei umgesetzt und enthält unter anderem folgenden Informationen: 

| Feld | Beschreibung |
|---|---|
| Asset-ID | Kennzeichnung des Assets |
| Asset-Name | Bezeichnung des Informationswertes |
| Beschreibung | Zweck und Funktion des Assets |
| Typ | Einordnung, z. B. Anwendung, Infrastruktur, Hardware oder Datenbestand |
| Abteilung / Prozess | Zuständiger Unternehmensbereich |
| Owner | Verantwortliche Rolle für das Asset |
| Standort / System | Technischer oder organisatorischer Standort |
| Lieferanten / Dienstleister | Externe Parteien mit Bezug zum Asset |
| Datenkategorien | Verarbeitete oder gespeicherte Informationsarten |
| Rechtsgrundlage | Relevante Rechtsgrundlage bei der Verarbeitung personenbezogener Daten |
| Vertraulichkeit | Bewertung des Schutzbedarfs hinsichtlich unbefugter Offenlegung |
| Verfügbarkeit | Bewertung des Schutzbedarfs hinsichtlich der Nutzbarkeit |
| Integrität | Bewertung des Schutzbedarfs hinsichtlich der Korrektheit und Unverändertheit |
| Kritikalität | Zusammenfassende Einschätzung der Bedeutung des Assets |
| Backup | Information zur Datensicherung |
| Patch-Status | Dokumentation des Patch- bzw. Aktualisierungsstatus |
| Letzte Änderung | Datum der letzten dokumentierten Änderung |
| Lebenszyklus | Aktueller Status des Assets |
| Anschaffung | Dokumentiertes Anschaffungsdatum, sofern relevant |
| Risiko-ID | Verknüpfung mit den Risiken aus dem Risikoregister |
| Maßnahmen (Annex A) | Zugeordnete relevante Maßnahmen aus ISO/IEC 27001:2022 Annex A |
